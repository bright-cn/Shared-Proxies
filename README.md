## 常见问题

### 什么是共享代理？
共享代理是由多个用户共同使用的 IP。如果你不要求独享 IP，它们是一种经济高效的选择。

### 共享代理可以用于多个会话吗？
可以，你可以使用会话持久性功能，在多个会话中使用同一个共享代理。

### 有哪些套餐可供选择？ 
Bright Data 提供灵活的定价模式，包括：

- **按量付费**：按 GB 收取固定费率。
- **订阅套餐**：提供月度、年度和自定义选项。

### Bright Data 的共享代理是否合规且使用安全？
